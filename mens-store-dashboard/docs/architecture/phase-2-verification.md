# Phase 2 verification

Phase 2 is complete for the currently exposed identity surface.

- PostgreSQL migrations create organization-scoped users, sessions, and audit
  events.
- Passwords are scrypt hashes; opaque session tokens are stored only as SHA-256
  hashes, expire after eight hours, and are revoked on logout.
- `/api/v1/users` derives organization identity from the authenticated session,
  requires `users:manage`, and records `USER_CREATED` audit events.
- The real PostgreSQL integration suite proves user creation, duplicate-email
  rejection, session revocation, audit persistence, and isolation from another
  organization.
- `/api/v1/openapi.json` is generated by Fastify Swagger from route metadata.
- API, contracts, and web coverage are each enforced at 100% for included
  application source; bootstrap and generated code exclusions are documented in
  the delivery plan.
